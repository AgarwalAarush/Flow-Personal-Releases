# Aion

A native macOS focus timer and personal workspace.

[Download Aion 1.3.25](https://github.com/AgarwalAarush/Flow-Personal-Releases/releases/tag/v1.3.25).

Starting a new Focus session from Full or Compact now hides the timer window.
Click the menu-bar timer to bring it back.

Requires macOS 14 or later; universal Intel and Apple Silicon app.
Application source remains private. This repository distributes installers and
signed update feeds only. Downloads are ad hoc signed and are not Apple Developer
ID signed or notarized. Respect macOS security warnings; do not disable Gatekeeper
or remove quarantine. Existing storage and update identity remain unchanged.
