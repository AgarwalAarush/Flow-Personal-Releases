# Aion

A native macOS focus timer and personal workspace.

[Download Aion 1.3.26](https://github.com/AgarwalAarush/Flow-Personal-Releases/releases/tag/v1.3.26).

Review day, week and month activity summaries, correct past activity categories,
and see whether capture is using the app, a website or a private window.
Website setup refreshes access live and includes stale-permission recovery.
A one-time regrant may be needed when updating from an ad hoc build.
Native website capture in Dia and Chrome remains Preview. Safari remains app-level tracking only.

Requires macOS14 or later; universal Intel and Apple Silicon app.
Application source remains private. This repository distributes installers and
signed update feeds only. Aion1.3.26 uses the existing Apple Development signing identity for consistent
app identity across updates. It is not Developer ID signed or notarized. Respect macOS security warnings; do not disable Gatekeeper
or remove quarantine. Existing storage and update identity remain unchanged.
